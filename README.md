Student Expenses Analytics Dashboard

An IBM Cognos Analytics project that analyzes 300 student transactions (Jan-Dec 2025) totaling ₹445,815. The dashboard shows spending by category, needs vs. wants, monthly trends, payment methods, and top expense items. Food is the top category at 27.6%, needs make up 62.4% of spend, and August is the peak month. These insights help students budget better and plan for high-spending months.
